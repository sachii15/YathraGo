# YathraGo – Smart Metro Bus Application

## Overview

YathraGo is a smart metro bus application designed to improve
public transportation through real-time tracking, passenger safety,
occupancy monitoring and digital services.

## Key Features

- Real-time GPS tracking
- Bus occupancy monitoring
- SOS emergency functionality
- Anonymous harassment reporting
- Live journey sharing
- Speed monitoring and alerts
- Digital payments
- Accessibility support
